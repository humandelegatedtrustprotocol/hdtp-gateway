# Security policy

If you find a vulnerability in hdtp-gateway, report it privately.

**Do not open a public issue for security reports.**

Email security@hdtp.io with the subject `[hdtp-gateway security]`, and include a reproduction
if you can.

The policy is the protocol's:
[hdtp-spec's SECURITY.md](https://github.com/humandelegatedtrustprotocol/hdtp-spec/blob/main/SECURITY.md).
It says that reports about the implementations go to this address, and it carries the
acknowledgment and status-update commitments and the terms of disclosure. This file adds none of
its own.
